# Home Assistant integration: [![Open your Home Assistant instance and start setting up.](https://my.home-assistant.io/badges/config_flow_start.svg)](https://my.home-assistant.io/redirect/config_flow_start/?domain=kospel_ppe4)

Click the badge above to jump straight into the KOSPEL PPE4 setup flow
(requires [My Home Assistant](https://my.home-assistant.io) — works on any instance
that serves the `my.home-assistant.io` redirect; on the same LAN it opens your own HA).

Manual alternative: *Settings → Devices & Services → Add Integration → KOSPEL PPE4*.
The config flow also **auto-discovers heaters** on the local /24 network.
